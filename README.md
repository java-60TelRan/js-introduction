# HW#14 definition
## write function minMax(...values)
### values - parameter matching any number of arguments (an argument may be either array or number)
### returns array with two elements: first element - minimal value, second element - maximal value
## examples
### minMax(1, 2, 3) => [1, 3]
### minMax(1, 2, 3, [100, 50]) => [1, 100]
### minMax(1, 2, 3, [100, 50], [-2, 40, 200]) => [-2, 200]
